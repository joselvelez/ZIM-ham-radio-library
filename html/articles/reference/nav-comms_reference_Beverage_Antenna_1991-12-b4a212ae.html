THE BEVERAGE ANTENNA: A PRACTICAL WAY OF ASSESSING THE RADIATION PATTERN USING OFF-AIR SIGNALS

A.G. Lyner, B.Sc., C. Eng., M.I.E.E.

Summary

This Report describes a method for assessing the performance of a Beverage, long wire, receiving antenna using off-air HF broadcast signals.

The method was used to assess the improvement in performance which should result from using a lower wire antenna. It indicated a 5 dB improvement in all-round rejection of off-beam interference for the antenna which was tested, as the antenna was lowered from a height of 3 m to 1 m.

Index terms: Antenna; HF; HF propagation; measurement; radio; reception; interference
